# Glossary

| TERM | MEANING | EXAMPLE |
| --- | --- | --- |
| Genuine | Not falsified, with proper intentions. | This is a genuine user who wants to open an account. |
| Authentic | Real & true, with the authority of the original creator. | This ID Document is authentic because it contains holographic security features. |
| Accurate | Given data reflects original data. No error.  | The customer’s name is accurate. I’ve cross-checked the database.  |
| Legitimate | Complies with given requirements . | This user is legitimate but a suspected fraudster according to our records. |
| Verified | Confirmed. Have gone through series of process checks. | This user is a verified fraudster.  |
| Complete | No missing information | The user has completed the form, but it contains errors. |
| ID Assurance | (Client-centric) Confidence that the user’s identity and overall information is assured.  | Innov8tif provides ID Assurance solutions. |
