# ID Capture Best Practices

![Image 1](media/concepts/id-capture-best-practices-img-8.png)


### **The Importance of Proper ID Document Capture**

Innov8tif’s OkayDoc is an ID document authentication module that uses mobile phone cameras to verify the legitimacy of ID documents. A bad capture can reduce authentication accuracy, leading to user onboarding failures.


### **Best Practices for ID Document Capture**

To ensure a successful ID document capture, users need to follow the following practices:

1. **Good Lighting**: Encourage users to capture their ID document in a well-lit area, with no glare or reflections. This helps the camera capture a clear image of the document.
2. **Proper Orientation**: Advise users to position the ID document flat and straight, with no excessive tilt or rotation.
3. **No Obstruction**: Remind users to ensure nothing is covering or obstructing the ID document, including fingers or other objects.
4. **Not Blurry**: Instruct users to keep the camera steady and maintain focus on the ID document to prevent a blurry image.
5. **Not Hidden in Shadow**: Recommend users to avoid capturing the ID document in areas with shadows, as this can cause parts of the document to be difficult to read.

### **Strategies to Improve Capturing Accuracy**

Businesses can implement the following strategies to encourage better capturing practices amongst users:

- **User Priming**: Provide clear instructions and examples of proper ID document capture at the beginning of the eKYC process to build awareness.
- **Real-time Feedback**: Innov8tif does provide an SDK (Software Development Kit) that offers real-time feedback during the live capture process. This can help users correct any issues with their capture before submitting the image for verification, reducing the need for manual intervention.
