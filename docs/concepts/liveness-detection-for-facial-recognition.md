# What Is Liveness Detection For Facial Recognition?

### What is Liveness Detection?

Liveness detection is a key component of most facial recognition systems today. It is employed in facial recognition biometric systems to differentiate between live subjects and fraudulent attempts.

Its purpose is to ensure that the biometric data being presented is real (from a live person) and not fake (spoofed images or printed masks).

---

### How Does It Work?

Liveness detection detects presentation attacks by identifying the characteristics of a live person. These techniques use algorithms and sensors to identify live biometric data such as faces, fingerprints, and voices.

In facial recognition systems, liveness detection algorithms will analyse subtle facial movements like blinking and head rotation to differentiate live faces from spoofed ones.

To detect facial presentation attacks, liveness detection uses **2D and 3D facial recognition technology, motion tracking, and thermal imaging** techniques to identify discrepancies in a person's face.

**There are two types of liveness detection:**

1. **Active liveness detection** — requires the user to perform specific actions (e.g., blinking, turning head, smiling) to prove they are live
2. **Passive liveness detection** — analyses the image or video without requiring user interaction, detecting spoofing through algorithmic analysis alone
