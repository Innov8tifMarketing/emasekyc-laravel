# Use Case 5: Gaming Industries — eKYC for Number Forecasting

## Clients
- **Da Ma Cai**
- **Magnum**

## Use Case
eKYC for number forecasting (betting/lottery) — regulatory compliance

## Regulatory Context
- In Malaysia, the betting gaming industry is governed by the **Betting Act 1953**, enforced by the **Ministry of Finance**
- Heavily regulated industry requiring identity verification

## Solution Highlights

### Filter Muslim Applicants Using eKYC
- Implementing eKYC to filter Muslim applicants by recognizing **'Islam' wording within Visual of MyKad**
- MyKad contains religion field which can be read via OCR

### Filter Applicants Less Than 21 Years Old
- Eliminate applicants under 21 years old using eKYC
- Age extracted from MyKad date of birth field

### Adopting by Major Players
- Major gaming industry players starting to adopt the same eKYC use case
- Can be run **24/7**
